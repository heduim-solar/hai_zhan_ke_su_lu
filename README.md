# 海战克苏鲁

这是魔兽争霸3自定义地图《海战克苏鲁》的源代码仓库。

* 框架最新版本可查看 https://github.com/heduim-solar/solar-rpg-map-ts-framework

## 项目简介

《海战克苏鲁》是一款基于魔兽争霸3的海战题材RPG地图，使用太阳TS框架（Solar Framework）开发。玩家可以驾驶各种战船在海上战斗，收集装备，挑战强大的BOSS。

## 技术栈

- **游戏引擎**: 魔兽争霸3 (Warcraft III)
- **开发框架**: 太阳TS框架 (Solar Framework)
- **编程语言**: TypeScript + Lua
- **脚本编译**: TypeScript 编译为 Lua

## 游戏特色

### 船只系统
- 多种类型战船：力量型、敏捷型、智力型
- 丰富的船只装备：船身、船帆、马达、船头、甲板、桅杆、炮弹等
- 独特的船只技能和主炮系统

### 游戏模式
- 教学模式
- 普通模式
- 寄生模式
- 献祭模式
- 真实难度

### BOSS挑战
- 克苏鲁 - 最终BOSS
- 克苏鲁之女
- 巨型海怪
- 无敌战舰号
- 大和号
- 更多BOSS等待挑战

### 系统玩法
- 进化系统
- 藏宝图探险
- 擂台挑战
- 深度海域探索
- 物品附魔
- 核心部件收集
- 杀敌抽奖
- 伤害排行榜

## 开发环境

### 必要条件
- 魔兽争霸3: 冰封王座 (Warcraft III: The Frozen Throne)
- 太阳TS框架编辑器

### 编译脚本
地图脚本使用 TypeScript 编写，通过太阳TS框架编译为 Lua 脚本。

## 安装使用

1. 克隆仓库到本地
2. 使用太阳TS框架编辑器打开项目
3. 编辑脚本后编译
4. 在魔兽争霸3中测试地图
